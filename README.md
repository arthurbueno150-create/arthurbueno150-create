## 🧠 Sobre mim

Olá! Sou **Arthur Bueno**, estudante de Ciência de Dados, interessado em descobrir padrões e transformar dados brutos em informações úteis.

Atualmente, estou desenvolvendo projetos acadêmicos de análise exploratória, limpeza e visualização de dados. Busco evoluir minhas habilidades em Python, SQL, estatística e Business Intelligence, sempre registrando meu aprendizado por meio de projetos práticos.

- 🔭 Desenvolvendo análises exploratórias com dados reais
- 📊 Aprendendo a criar visualizações e relatórios claros
- 🧹 Praticando limpeza, transformação e organização de dados
- 🌱 Evoluindo em Ciência de Dados, BI e machine learning
- 💬 Gosto de conversar sobre Python, SQL, estatística e análise de dados
